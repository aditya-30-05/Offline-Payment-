# OfflinePay AI – Secure Offline Digital Payments

# 🎯 Problem Statement

Digital payment systems rely heavily on internet connectivity. During network outages or in remote areas, users cannot perform digital transactions.

OfflinePay AI provides a secure mechanism for making payments even when no internet or mobile network is available.

 # 🔄 Payment Flow
User enters payment amount.
App creates a secure transaction.
Transaction is digitally signed.
Payment is transferred using:
NFC
Bluetooth
QR Code
Merchant verifies the signature.
Transaction is stored locally.
Once online, both devices sync with the server.
Server verifies and settles the transaction.
